# WireWOL

집에 있는 PC를 폰에서 리모컨처럼 켜고(Wake-on-LAN), 끄고(원격 종료), WireGuard VPN을 켰다 끌 수 있게 해주는 앱입니다.

버튼 네 개(PC 켜기 / PC 끄기 / 와이어가드 켜기 / 와이어가드 끄기)가 전부인 단일 화면 안드로이드 리모컨 앱과, PC 쪽에서 종료 명령을 받아 실행해주는 최소한의 트레이 상주 프로그램(Windows)으로 구성됩니다.

## 구성 요소

- **안드로이드 앱** — 폰에서 쓰는 리모컨. `android/` 폴더.
- **Windows 컴패니언(wirewol.pyw)** — PC를 켜는 것(WOL)은 매직 패킷을 리모컨이 직접 쏘기 때문에 PC 쪽에 프로그램이 없어도 되지만, **PC를 끄는 것은 PC가 뭔가 받아서 실행해줘야 하므로** 이 프로그램이 필요합니다. `windows/` 폴더.

## 설치

### 1. Windows 컴패니언 설치 (PC 쪽)

원격으로 켜고 끄고 싶은 PC에서 진행합니다.

1. [Releases](https://github.com/huny4daniel/wire-wol_v/releases) 페이지에서 최신 버전의 `WireWOL_vX.Y.Z.exe`를 내려받습니다.
2. 실행하면 알림 영역(트레이)에 아이콘이 하나 뜹니다. 별도 설치 과정 없이 그대로 동작합니다.
3. 트레이 아이콘을 우클릭 → **자동 시작 등록**을 누릅니다(등록된 상태에서 다시 누르면 해제됩니다).
   - UAC 창이 뜨면 승인하세요. 이 단계를 거쳐야 PC를 재부팅했을 때(아무도 로그인하지 않은 상태여도) 폰에서 보낸 종료 명령을 받을 수 있습니다.
   - UAC 승인을 건너뛰면 "로그인 시 트레이 실행"만 등록되고, 부팅 직후 자동 서버 시작은 등록되지 않습니다. 이 경우 로그인해서 트레이가 뜬 상태에서만 원격 종료가 가능합니다.
4. 트레이 아이콘을 우클릭 → **연결 정보 보기**를 눌러 QR 코드를 화면에 띄워둡니다(다음 단계에서 폰으로 스캔합니다).
   - 이 QR에는 PC의 IP, 포트, 인증 토큰, MAC 주소가 그대로 담겨 있으니 다른 사람에게 노출되지 않도록 주의하세요.

소스에서 직접 실행하려면:
```
pip install -r windows/requirements.txt
python windows/wirewol.pyw
```

### 2. 안드로이드 앱 설치 (폰 쪽)

1. [Releases](https://github.com/huny4daniel/wire-wol_v/releases) 페이지에서 최신 버전의 `WireWOLAndroid_vX.Y.Z.apk`를 내려받아 설치합니다(출처를 알 수 없는 앱 설치 허용 필요).
2. 앱을 실행하면 리모컨 화면이 뜹니다. 아직 연결 정보가 없으므로 **설정** 버튼을 눌러 설정 화면으로 이동합니다.
3. **PC 등록**을 누르고 입력 방법을 고릅니다.
   - **카메라로 스캔** — 1단계에서 PC 화면에 띄워둔 QR 코드를 스캔합니다.
   - **갤러리에서 QR 이미지 불러오기** — QR을 캡처해둔 이미지가 있다면 그 이미지에서 바로 읽습니다.
   - **직접 입력** — QR 없이 PC 주소/포트/토큰/MAC을 손으로 입력합니다.
   - 등록에 성공하면 PC의 IP/포트/토큰과 MAC 주소가 함께 저장됩니다.
4. **‹ 뒤로**를 눌러 메인 화면으로 돌아오면 상태 카드에 PC 상태, 연결 대상, MAC 주소가 표시됩니다.

이 두 단계만으로 PC 켜기 / PC 끄기 기능을 바로 쓸 수 있습니다. 아래 WireGuard, 원격 WOL은 선택 사항입니다.

## 사용 방법

메인 화면의 버튼 네 개와 **예약** 버튼으로 모든 조작을 합니다.

### 상태 카드

메인 화면이 떠 있는 동안 5초마다 PC가 응답하는지 자동으로 확인해 **켜짐 / 꺼짐 / 응답 없음**을 보여줍니다.

- 집 밖에서 와이어가드가 꺼져 있어 PC에 닿지 않는 경우엔 "꺼짐"으로 단정하지 않고 "와이어가드를 켜야 확인됩니다"라고 구분해 표시합니다.
- 그 아래에 연결 대상(PC 주소:포트), MAC 주소, WireGuard 연결 상태, 걸려 있는 종료 예약이 함께 표시됩니다.

### PC 켜기

**PC 켜기** 버튼을 누르면 저장된 MAC 주소로 매직 패킷을 보냅니다. PC가 완전히 꺼져 있어도(전원 코드만 꽂혀 있으면) 켜집니다.

- 폰이 PC와 같은 와이파이(같은 LAN)에 있거나, WireGuard로 홈 네트워크에 연결되어 있어야 패킷이 도달합니다.
- WireGuard 설정이 등록되어 있고 PC에 직접 닿지 않으면(집 밖이면) **와이어가드를 자동으로 켠 뒤** 신호를 보냅니다. 매번 손으로 와이어가드부터 켤 필요가 없습니다.
- 버튼을 누른 뒤 처음 15초는 1초 간격, 그 이후엔 5초 간격으로 PC 전원 상태를 재확인하며, 부팅이 완료되어 컴패니언이 응답하면 상태 카드가 "켜짐"으로 바뀝니다.
- 설정의 "PC 켜기 후 자동 종료"를 사용 중이면, 켜짐이 확인될 때 정해둔 시간 뒤로 종료 예약이 자동으로 걸립니다.
- 아래 "원격 WOL(선택)"을 설정해두면 집 밖에서 와이파이/WireGuard 없이도 공유기를 통해 켤 수 있습니다.

### PC 끄기

**PC 끄기** 버튼을 누르면 확인 창이 뜨고, 확인하면 Windows 컴패니언에 종료 명령을 보냅니다.

- 실제 종료까지 10초의 유예 시간이 있으며, 그동안 화면 하단 스낵바의 **취소**를 눌러 되돌릴 수 있습니다(오조작 방지).
- 집 밖이면 PC 켜기와 마찬가지로 와이어가드를 자동으로 켠 뒤 명령을 보냅니다.
- PC가 응답하지 않으면 절전 상태일 수 있으므로 깨우기 신호를 보낸 뒤 최대 30초간 기다렸다가 한 번 더 시도합니다. 그래도 응답이 없으면 실패 메시지가 표시됩니다.
- 와이어가드를 켠 상태에서 끄기에 성공하면, PC가 실제로 꺼진 것을 확인한 뒤 와이어가드도 자동으로 꺼집니다. 그 사이 종료를 취소하거나 와이어가드/PC 켜기 버튼을 직접 누르면 자동 끄기는 해제됩니다.

### 예약 끄기

**예약** 버튼을 누르면 몇 시간 몇 분 뒤에 끌지 타이머 형식으로 고를 수 있습니다(최대 23시간 59분).

- 확인하면 그 시간 뒤 자동으로 종료되도록 예약됩니다. 상태 카드에 예정 시각이 표시되며, 눌러서 언제든 취소할 수 있습니다. 예정 시각이 지나면 표시는 자동으로 사라집니다.
- 이미 걸려 있는 예약(즉시 끄기든 예약 끄기든)이 있는 상태에서 다시 걸면 기존 예약은 취소되고 새 예약으로 덮어써집니다.
- 앱을 껐다 켜도 예정 시각은 유지되어 계속 표시됩니다.

### 와이어가드 켜기 / 끄기

집 밖에서도 PC와 같은 네트워크에 있는 것처럼 통신하기 위한 VPN 스위치입니다. 켜기/끄기 버튼이 따로 있으며, 누른 상태를 그대로 유지합니다(다른 화면으로 이동하거나 최소화해도 자동으로 꺼지지 않습니다. 단, 앱이 완전히 백그라운드로 내려가면 배터리 절약을 위해 자동으로 껐다가, 다시 앱으로 돌아오면 자동으로 되살립니다).

사용하려면 먼저 설정 화면에서 WireGuard 설정을 등록해야 합니다:

1. 공유기 관리 화면 등에서 발급한 WireGuard 설정 QR 코드(표준 `.conf` 내용을 담은 QR)를 준비합니다.
2. 앱 설정 화면 → **WireGuard 설정 스캔**으로 해당 QR을 카메라로 스캔하거나, 캡처해둔 QR 이미지를 갤러리에서 불러옵니다.
3. 메인 화면에서 **와이어가드 켜기**를 누르면 최초 1회 VPN 연결 허용 팝업이 뜨고, 승인하면 연결됩니다.

WireGuard를 설정하지 않았다면 이 버튼들은 사용할 수 없다는 안내만 표시됩니다 — 필수 기능이 아니라 선택 사항입니다.

터널은 **등록한 PC가 있는 대역(/24)으로 가는 통신만** 맡습니다. WireGuard 설정의 AllowedIPs·DNS는 무시하므로 폰의 다른 인터넷 통신은 터널을 거치지 않고, 터널이 막혀도 인터넷은 끊기지 않습니다. 폰가 PC와 같은 네트워크(집 안)에 있으면 PC가 꺼져 있어도 와이어가드를 켜지 않고, 켜 둔 채 집에 들어오면 자동으로 끕니다.

## 설정 화면 (자주 쓰지 않는 기능)

메인 화면의 **설정** 버튼으로 들어갑니다. 각 항목 아래 현재 저장된 값이 표시됩니다.

- **PC 등록** (필수) — 위 설치 2단계에서 다룬 PC 연결 정보 등록(카메라 스캔 / 갤러리 이미지 / 직접 입력). 항목 아래에 등록된 PC 주소와 MAC 주소가 표시됩니다.
  - 연결 정보 QR에 담긴 MAC이 잘못된 경우(PC에 랜카드가 여러 개라 엉뚱한 어댑터가 잡힌 경우)엔 **직접 입력**을 열어 MAC만 고치면 됩니다. 기존 값이 미리 채워져 있습니다.
- **WireGuard 설정 스캔** (선택) — 위 "와이어가드 켜기/끄기"에서 다룬 VPN 설정 등록.
- **원격(외부망) WOL 설정** (선택) — 공유기(iptime 등)에 내장된 원격 관리 기능을 이용해, 집 와이파이 밖에서도(공유기의 외부 접속 포트가 열려 있다면) PC를 깨울 수 있게 하는 보조 경로입니다. 공유기 관리자 페이지 주소/포트, 관리자 아이디/비밀번호를 입력해두면 PC 켜기 버튼을 누를 때 매직 패킷과 함께 이 경로로도 켜기 신호를 보냅니다.
  - 공유기 관리자 계정 정보이므로, 신뢰할 수 있는 개인 기기에만 설정하세요.
- **PC 켜기 후 자동 종료** (선택, 기본값 사용 안 함) — 원격으로 PC를 켜두고 깜빡 잊고 못 끄는 것을 막아줍니다. 사용으로 켜고 시간을 정해두면, PC 켜기로 켠 PC가 켜진 것이 확인되는 순간 그 시간 뒤로 종료 예약이 자동으로 걸립니다(예약 버튼을 대신 눌러주는 것과 같으며, 상태 카드에서 탭해 취소할 수 있습니다).
  - 이미 걸어둔 종료 예약이 있으면 덮어쓰지 않습니다.
  - PC 켜기를 누르고 앱을 내렸다가 10분 안에 다시 열면 이어서 켜짐을 확인해 예약을 겁니다.
- **설정 내보내기 / 불러오기** — 위 설정을 전부 비밀번호로 암호화한 파일 하나(`wirewol_settings.json`)로 저장하거나, 그 파일을 불러와 그대로 복원합니다. 폰을 바꿀 때나 [WireWOL PC](https://github.com/huny4daniel/wire-wol-pc_v)(윈도우판 리모컨)와 설정을 옮길 때 씁니다 — 두 앱이 같은 파일 형식을 씁니다.
  - 파일에는 PC 토큰, WireGuard 개인키, 공유기 비밀번호가 담기므로 내보낼 때 비밀번호를 정해야 하고, 불러올 때 같은 비밀번호가 필요합니다.
  - 불러오면 지금 저장된 설정은 지워지고 파일의 설정으로 바뀝니다.
- **저장된 정보 초기화** — 위에서 저장한 연결 정보/MAC/WireGuard 설정/원격 WOL 설정/자동 종료 설정을 모두 삭제합니다.

## 참고 사항

- **인증**: 안드로이드 앱과 Windows 컴패니언 사이의 모든 요청은 페어링 QR에 담긴 고정 토큰으로 인증됩니다. QR과 토큰이 외부에 노출되지 않도록 주의하세요.
- **네트워크**: 안드로이드 앱은 컴패니언과 평범한 http로 통신합니다(같은 LAN이거나 WireGuard 터널 안에 있다고 가정). 인터넷에 직접 노출된 포트로 열어두지 마세요.
- **Windows 컴패니언 자동 시작을 등록하지 않으면**: 로그인 전(부팅 직후)에는 종료 명령을 받을 수 없습니다. 항상 원격 종료가 가능하길 원한다면 반드시 트레이 메뉴의 "자동 시작 등록"을 해두세요.

## 소스에서 빌드하기

**Windows 컴패니언**
```
pip install -r windows/requirements.txt
python windows/wirewol.pyw
```

**안드로이드 앱**
```
cd android
./gradlew assembleDebug   # Windows에서는 gradlew.bat
```
compileSdk/targetSdk 35, minSdk 26, Kotlin + AGP 8.7.3 + Gradle 8.9 환경이 필요합니다.

버전 태그(`v*`)를 푸시하면 GitHub Actions가 Windows 컴패니언 exe와 안드로이드 apk를 함께 빌드해 릴리즈로 올립니다(`.github/workflows/release.yml`).
